Built a full-stack restaurant automation system from scratch.

The system includes 5 modules: admin panel, waiter app, cashier panel, kitchen screen, and QR menu for guests — all working in real time.

Backend: Python, Django REST Framework, PostgreSQL, JWT authentication, role-based access control.

Frontend: React, JavaScript, CSS — responsive UI for all devices (tablet, desktop, mobile).

Features: table & order management, kitchen Kanban board, stop-list, payments (cash / card / dengi.kg), receipt printing, business analytics.

Designed and developed end-to-end — from architecture to deployment.
